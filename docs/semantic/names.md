# Donabe 名前解決の仕様
## 1. 概要
名前解決とは、プログラム中に記述された識別子が、どの宣言を指しているかを決定する処理である。

本仕様書では、Donabeにおける識別子の宣言とその解決について定義する。
なお、各構文についての詳しい定義は、[構文仕様](../syntax/syntax.md)で定義する。

## 2. 定義
### 2.1 識別子
識別子とは、プログラム中の定数、変数、関数、引数の名前である。命名規則については[構文仕様](../syntax/syntax.md)で定義する。
### 2.2 宣言
宣言とは、新たな識別子を参照可能なものとして定義することである。
`let`文、`var`文、関数定義文、引数名の宣言がこれに当たる。詳しくは、[宣言](#3-宣言)節で説明する。

## 3. 宣言
### 3.1 定数宣言
定数宣言は、`let`文により行う。
例:
```
let nabe = "鍋";
```
### 3.2 変数宣言
変数宣言は、`var`文により行う。
例:
```
var pot = "pot";
```
### 3.3 関数宣言・引数宣言
関数宣言は、関数宣言文により行う。引数宣言は、関数定義文の一部である。
例:
```
func add(a: Int, b: Int) -> Int {...}
```
この場合、引数宣言は`a: Int`と`b: Int`である。

引数を宣言しないことも可能である。
```
func getNum() -> Int {...}
```

## 4. スコープ
### 4.1 グローバルスコープ
グローバルスコープとは、どのブロックにも入っていないスコープである。
このスコープには、`let`文、`var`文、関数定義文のみを記述できる。また、ここで宣言された識別子は、プログラム中のどこからでも参照可能になる。
### 4.2 関数スコープ
関数スコープとは、関数定義、または関数リテラルにより発生するスコープである。
このスコープには、任意の文を記述できる。ここで宣言された識別子は、そのスコープ、またはその内側のスコープからのみ参照が可能である。
また、関数スコープには、その関数の引数が宣言される。これもそのスコープ、またはその内側のスコープからのみ参照可能である。
### 4.3 ブロックスコープ
ブロックスコープとは、関数定義文と関数リテラル以外のブロックを持つ文により発生するスコープである。ブロックの構文については、[ブロック文](../syntax/syntax.md#31-ブロック文)にて定義する。
このスコープには、任意の文を記述できる。ここで宣言された識別子は、そのスコープ、またはその内側のスコープからのみ参照可能である。
### 4.4 前方参照
前方参照とは、ある識別子の宣言時に、後から宣言される識別子を参照することである。
例:
```
let a = b + 10;
let b = 20;
```
この場合、`a`の初期化式で、まだ宣言されていない`b`を参照している。これが前方参照である。

前方参照は、グローバルスコープでのみ可能である。その他のスコープで前方参照を行うことは禁止されている。

## 5. シャドーイング
シャドーイングとは、親スコープで宣言された識別子と同名の識別子を、子スコープで宣言することである。
例:
```
let a = 10;
{
    let a = 20;
    print(a);   //20
}
print(a);   //10
```
この場合、外側スコープの`a`と内側スコープの`a`は、全く異なるものとして扱われる。これがシャドーイングである。

### 5.1 外側スコープの変数の参照
シャドーイングを行うと、同名の外側スコープの識別子を参照することはできなくなる。
> [!TIP]
> この制約を避けるには、シャドーイングを行わず、子スコープで別名変数を宣言すればよい。

### 5.2 同じスコープ内でのシャドーイング
同じスコープ内で、同じ名前の識別子を複数宣言することは許可されていない。
例:
```
let a = 10;
let a = 20; //エラー
```
